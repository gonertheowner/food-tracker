# 0004. КБЖУ Записи фиксируется снапшотом

Каждая Запись («съеденное») хранит вычисленные значения КБЖУ на момент создания, а не пересчитывает их на лету из текущего Продукта или Блюда.

**Контекст:** Продукт и Блюдо можно отредактировать (исправить КБЖУ, изменить состав рецепта). Если бы Запись ссылалась только на Продукт/Блюдо и считала КБЖУ динамически, правка задним числом исказила бы историю съеденного за прошлые дни.

**Решение:** при создании Записи копировать в неё итоговые калории/белки/жиры/углеводы. История неизменна; правки Продукта/Блюда влияют только на будущие Записи.

**Последствия:** небольшая денормализация (дублирование чисел в Записи). Это сознательная плата за достоверность исторических отчётов по дням/неделям/месяцам.
