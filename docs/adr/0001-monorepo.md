# 0001. Монорепо: бэкенд и фронтенд в одном репозитории

Spring Boot бэкенд и React PWA фронтенд живут в одном Git-репозитории (`backend/`, `frontend/`), а не в двух отдельных.

**Контекст:** проект ведёт один разработчик, фронт и бэк меняются одновременно и тесно связаны контрактом REST API.

**Решение:** монорепо. Одна точка клонирования, атомарные коммиты, которые меняют API и его потребителя вместе, единый `docker-compose.yml` для локального запуска и деплоя.

**Последствия:** в одном дереве соседствуют две разные сборки (Maven + npm/Vite). CI и линтеры настраиваются по поддиректориям. Для одного разработчика это дешевле, чем синхронизировать два репозитория.
