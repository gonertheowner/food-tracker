# 0002. Технологический стек и требование HTTPS для PWA

Бэкенд — Java 21 + Spring Boot 3 (Maven) + PostgreSQL. Фронтенд — React + Vite + TypeScript как PWA. Деплой — Docker Compose (nginx + spring + postgres) на одной VM (Selectel).

**Контекст:** автор пишет бэкенд на Java/Spring профессионально, поэтому бэк выбран по знакомству. Фронт — React из-за крупнейшей экосистемы (больше примеров и помощи для разработчика, слабо знакомого с фронтендом). Цель — бесплатный self-hosting на маленькой VM.

**Ключевое ограничение:** PWA с service worker требует HTTPS (кроме localhost). Поэтому нужны доменное имя (подойдёт бесплатный DuckDNS) и TLS-сертификат (Let's Encrypt). Без HTTPS «жить как устанавливаемое PWA» невозможно — это не опция, а обязательное условие, заложенное в выбор nginx как точки терминации TLS.

**Лок-ин:** смена любого из Spring / PostgreSQL / React — это переписывание соответствующего слоя. Принято осознанно ради знакомого бэка и зрелого фронт-стека.
