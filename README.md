# Food Tracker

Личный трекер питания: учёт съеденного и подсчёт КБЖУ (калории, белки, жиры, углеводы) по дням, неделям и месяцам. Self-hosted, бесплатный, как PWA.

## Зачем

Платные трекеры (FatSecret и аналоги) надоели: подписка дорогая, а оплатить картой РФ из-за региона не получается. Поэтому — свой трекер для личного пользования, развёрнутый на собственной VM.

## Что внутри (MVP)

- **Продукты** — база еды с КБЖУ на 100 г (сырые ингредиенты, брендированные товары, ресторанные позиции). Старт с небольшого seed'а, остальное добавляется вручную.
- **Блюда** — собственные рецепты из Продуктов, приватные или публичные.
- **Записи** — журнал съеденного: Продукт или Блюдо + граммы + тип приёма пищи (завтрак/обед/ужин/перекус). КБЖУ фиксируется снапшотом.
- **Цель** — дневная норма КБЖУ на пользователя.
- **Отчёты** — сводка съеденного за день/неделю/месяц в виде столбиков и круговой диаграммы, в сравнении с Целью.
- **Вход** — минимальный JWT-логин (пока один seed-пользователь).

Доменный словарь — в [CONTEXT.md](CONTEXT.md). Модель данных — в [docs/data-model.md](docs/data-model.md).

## Стек

| Слой | Технология |
|------|-----------|
| Бэкенд | Java 21, Spring Boot 3, Maven |
| БД | PostgreSQL (миграции — Liquibase) |
| Фронтенд | React + Vite + TypeScript, PWA (vite-plugin-pwa) |
| Графики | Recharts |
| Деплой | Docker Compose: nginx (TLS) + spring + postgres, на VM Selectel |
| HTTPS | домен (DuckDNS) + Let's Encrypt — **обязателен для PWA** |

Решения и их обоснования — в [docs/adr/](docs/adr/). Соглашения по коммитам и веткам — в [CONTRIBUTING.md](CONTRIBUTING.md).
